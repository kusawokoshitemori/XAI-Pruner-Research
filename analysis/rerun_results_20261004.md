# 修正後GPU再実行の結果

2026-10-04、conda XAIPruner / RTX 3070で全件再実行を完了。GPUが見えなかった原因は実行制限内での確認で、制限外では同じ環境から利用できた。CPU全件試行は途中停止。CPUの8/64画像試行は動作確認として実施済み。

## 修正内容

- `_stabilize(0)`にもepsilonを加え、ゼロがゼロのまま残る問題を修正。
- 全ゼロ関連度のTransformer Filterはゼロで返す。非ゼロ関連度の選択signed sumがゼロならsnapshotとイベントを記録し停止。
- 全バッチ・全LayerNormの有限性を監視。先頭2バッチ制限を超えて異常イベントを記録。
- 新規/累積スコアとFitnessに非有限値があれば停止。NaNを重要度0に置き換える処理は行わない。
- Python randomをseed設定、親と候補をソートして列挙。Pythonのsetをrandom.sampleに直接渡さない。
- 異常時画像snapshot、例外、有限な再計算の件数を追加。集計にNaN警告・健全性・最終評価を表示。

6件の回帰テストとgit diff --checkを通過。全実画像のスコア計算・EA100世代・モデル構築・検証評価まで終了した。
